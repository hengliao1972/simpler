# 2026-8-5 cross-core 严格插入串行区分析

本目录归档 B256 cross-core shared TensorMap 的一次严格插入串行链实验分析。
原始采集目录为
`outputs/pa_scheduler_cross_core_shared_swimlane_20260805_002541_1965504/ccec`，
任务数为 1280。

这份采集来自后来已经撤回的 BUILT-ready 实验分支，只保留为历史取证，不代表
当前仅保留三项性能优化后的代码基线，也不得据此恢复已撤回协议。

## 文件说明

- `cross_b256_serial_detail_swimlane_782p890us.json`：在完整泳道基础上离线补出
  严格插入链细分事件，可直接使用现有泳道查看方式打开；设备侧 raw record
  没有增加字段。
- `cross_b256_serial_analysis_782p890us.json`：机器可读的完整分析结果。汇总位于
  `register_breakdown.strict_insert_chain`，逐 task 数据位于
  `register_breakdown.strict_insert_chain.steps`。

## 严格插入链闭合结果

严格插入链从 task 0 进入 Register 开始，到 task 1279 关闭 Register 结束，
总计 782.890 us。以下项目按 task-id 链每步只计算一次，合计与父区间完全相等。

| 串行链组成 | 耗时（us） | 占比（%） |
| ---------- | ---------: | --------: |
| 首个 task 进入串行区 | 0.020 us | 0.0026% |
| 前任已完成、后继 owner 尚未进入 Register | 70.912 us | 9.0577% |
| completion 发射至后继 return-ready 观察 | 613.307 us | 78.3388% |
| 发布 writer metadata | 91.529 us | 11.6912% |
| 准备 completion 发布 | 3.880 us | 0.4956% |
| completion source-issue | 2.460 us | 0.3142% |
| completion 发布后的收尾 | 0.782 us | 0.0999% |
| 合计 | 782.890 us | 100.0000% |

其中 `completion 发射至后继 return-ready 观察` 包含 completion 的完成与
可见性、后继核发起 Load 及其返回延迟，不能解释成某一条 atomic 指令自身的
延迟。owner 提前到达后等待前任的区间与前一串行链步骤并行，分析文件单独记录
在 `owner_wait_predecessor_overlap`，不会重复加入上述串行关键路径。

`cross_core/PA调度器分离版实现过程.md` 的 S6.73。
