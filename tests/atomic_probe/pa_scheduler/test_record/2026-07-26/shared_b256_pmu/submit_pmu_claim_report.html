PMU cycle 频率校准

本机受控 cold/warm 同窗证据：PMU cycle_delta = 1,817,457，1 ns SYS_CNT tick_delta = 1,101,593 ns；二者相除为 1.649844 cycles/ns（约 1.65 GHz）。

当前报告换算频率：ALL = 1.649844、AIC = 1.650062、AIV = 1.649731 cycles/ns。公式：等效 µs = PMU cycles / (cycles/ns) / 1000。

SYS_CNT 仍按 1 ns/tick 解释；表中的 PMU 时间是每个物理子核 gate 内 cycle 的校准等效时间。它不是 96 核 cycle 求和后的墙钟时间，也不替代独立记录的完整 Submit 墙钟。
